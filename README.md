# The Midnight Edition

A self-paced security logging and event correlation lab set in the overnight shift at North Quay Press. Students use 13 fictional original records to investigate a print delay and two network transfers. Eight practical assignments and sixteen short practice clippings support a planned 75–95 minute class. Each station includes worked examples, optional hints and retries. The last station produces a signed hand-off and unlocks a personalised PNG certificate.

## Run locally or on GitHub Pages

Open `index.html` in a current browser with JavaScript enabled. For GitHub Pages, copy these five files together into the directory that will serve the lab. Keep their names and relative positions.

- `index.html`
- `styles.css`
- `cases.js`
- `app.js`
- `STUDENT-GUIDE.txt`

The page runs entirely in the browser. It uses relative asset paths and also works under a repository subdirectory. The archive and simulated enquiries use supplied data. The AI draft is a prepared classroom example. No accounts or API keys are required.

## Classroom use

Share the published lab and student guide with learners. Keep `INSTRUCTOR-ANSWER-KEY.txt` in your instructor copy if you want to withhold solutions from your published site. Static client-side grading is intended for practice.

Answers and progress are saved in browser storage for this edition when storage is available. Returning learners should use the same browser profile and site address. The Midnight Edition uses its own progress record. Previously earned Case Relay progress does not transfer to this case. The learner downloads a copy of the signed report for manual review of their written follow-up.
