# Harbour After Dark

A beginner security logging and event correlation lab set in Signal Harbour. A delayed print job introduces the idea of a log. Learners then compare clocks, connect sessions across sources, test a delivery permit and hand over a carefully qualified finding.

## Use the lab

Open `index.html` in a modern browser with JavaScript enabled, or serve the files together on GitHub Pages. The lab is static and self-contained. Its two illustrated canvases, story captions, search, practice cases and permit checker run locally in the browser.

Plan roughly 80–100 minutes for a class that watches the fifteen scenes, reads the evidence, explains its decisions and writes the five chapter entries. Individuals work at their own pace. There are 45 decisions and 15 additional evidence fields across five fresh practice cases. Each chapter ends with a written entry. Structured answers are checked automatically. The instructor reviews the notes in the exported report.

## Files for GitHub Pages

Place the following files side by side in the published directory. A project subdirectory is supported.

- `index.html`
- `styles.css`
- `cases.js`
- `harbour.js`
- `projector.js`
- `app.js`
- `STUDENT-GUIDE.txt`

Keep `INSTRUCTOR-ANSWER-KEY.txt` in the instructor copy to withhold the answer sheet from the public site. Static client-side grading is intended for practice.

## Progress and completion

The browser stores answers and drafts under a new key for Harbour After Dark. Use the same browser profile and site address to resume. The earlier Midnight Edition uses a different progress record. A previously signed Midnight Edition hand-off in this browser appears in My logbook. After completing the new case, a learner can download a named PNG certificate and a TXT report containing their five entries, evidence checks and decision explanations.

Motion follows the browser's reduced-motion preference on a first visit. Pause motion is available at all times. Learners can step through all illustrated frames and read every caption manually.
