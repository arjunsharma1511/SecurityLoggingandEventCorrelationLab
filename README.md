# Case Relay Security Logging and Event Correlation Lab

An animated, beginner-friendly SOC investigation lab with six fictional cases and 24 guided challenges. Learners practise SIEM search, inspecting original source records, normalising event times, linking related events, preserving evidence, verifying AI summaries and escalating with a written hand-off. Allow 75–95 minutes, including reflection.

Open `index.html` in a modern browser. The fictional logs and AI drafts are supplied locally. Replay, grading, progress and downloads all run in the browser. Learners can pause motion and download a named PNG certificate after completing all 24 challenges.

## GitHub Pages

Publish `index.html`, `styles.css`, `cases.js`, `app.js` and `STUDENT-GUIDE.txt` together in the publishing folder. These files work under a project path and need no build. Share `INSTRUCTOR-ANSWER-KEY.txt` separately. The graded responses are part of the client-side lab, so assess independent reasoning with the written hand-off.
